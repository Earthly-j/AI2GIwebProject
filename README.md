# KURO Logi — 홈페이지 (HTML + 순수 CSS)

`kurologi.jp` 홈페이지를 **순수 CSS**로 재구성했습니다. Bootstrap 클래스는 쓰지
않았습니다 — 유틸리티 클래스(`col-lg-4`, `card-body`, `d-flex`, `btn-dark` …) 대신
의미 있는 이름(`col--one-third`, `card__body`, `btn--dark`)을 사용합니다.

**한 페이지, 한 CSS, 데스크톱 전용.** 미디어쿼리 없음.

### 마이페이지 구성

**종합현황에서 나의 정보·나의 사서함 주소를 마이페이지로 옮겼습니다.**
종합현황은 이제 5개 섹션입니다:
요약 탭 · 현황판 · AI 신청서 자동 생성 · 공지/환율/1:1 · 자주하는 질문

마이페이지는 3개 영역입니다:

| 영역 | 내용 |
|---|---|
| 나의 정보 | 6칸 표 — 등급·포인트·친구 추천 포인트·예치금·회원번호·이용실적 |
| 나의 사서함 주소 | 센터 3개 카드 + Copy All |
| 마이페이지 관리 하기 | 관리 메뉴 **3개** (할일) |

**계정관리** — 상단 4개 바로가기, 회원 요약 다크 바, "회원정보 수정" 표

### 주 메뉴를 고치려면

메뉴는 **`index.html` 하나만** 고치면 됩니다. 나머지 11개 페이지는
`tools/sync-nav.mjs` 가 홈페이지 메뉴를 그대로 복사해서 맞춰 줍니다.

```bash
# 1) index.html 의 <nav> 를 수정
# 2) 링크할 페이지가 새로 생겼다면 tools/sync-nav.mjs 의 PAGE_BY_LABEL 에 추가
# 3) 12개 페이지에 반영
node tools/sync-nav.mjs
```

스크립트가 하는 일:

- 홈페이지의 메뉴를 그대로 복사 (메뉴가 페이지마다 달라지는 것을 막음)
- 각 페이지 위치에 맞게 링크 앞에 `../` 를 붙임
- 현재 보고 있는 항목에 `is-current` 표시
- 상단 항목을 누르면 그 항목의 첫 페이지로 이동하게 연결
- 홈페이지 메뉴가 예상(5개 항목)과 다르면 **에러를 내고 멈춤**

## 클래스 이름 규칙

BEM 스타일로 통일했습니다. `블록__요소--변형`:

```
card            카드 전체
card__body      카드 안쪽 여백 영역
card--pad       위아래 20px 여백을 더 주는 변형
```

## 색상과 폭 바꾸기

각 CSS 파일 맨 위 `:root` 한 곳만 고치면 전체 톤이 바뀝니다:

```css
:root {
  --teal:      #159692;   /* 헤더, 기본 버튼 */
  --blue:      #107abd;   /* 링크, 포인트 */
  --red:       #dd4b39;   /* 경고, 강조 */
  --container: 1360px;    /* 전체 폭 */
  --gutter:    15px;      /* 좌우 여백 */
}
```

`tools/compare-styles.mjs` 가 원본 사이트와 이 페이지를 헤드리스 크롬으로 각각
열고, 같은 요소의 **계산된 스타일**을 읽어 비교합니다.

```bash
node tools/compare-styles.mjs
```

- 서비스안내 5개 페이지: 색상 픽셀 검증 완료

- 구매대행·배송대행: 색상 픽셀 검증 완료 (머리글 `#e4f0f9`, 버튼 `#1e3354`)

## 확인하지 못한 것

- **자바스크립트는 홈페이지 탭·팝업만** 동작합니다. 나머지 페이지의
  체크박스·파일 선택·등록 버튼은 겉모양만입니다.
- **320~499px 폭은 확인하지 못했습니다.** 헤드리스 크롬이 최소 500px 이라
  그 아래는 캡처할 수 없었습니다. 데스크톱 전용이라 미디어쿼리도 없습니다.
- **팝업 내부**: 원본 팝업은 이미지 한 장이라 안쪽은 근사치입니다.
- **엑셀 샘플 파일**은 실제로 받아지지 않습니다 (버튼만).
- **로그인 후 동작**은 확인할 수 없습니다. 값은 전부 정적입니다.

## 내용 주의

주소·전화번호·계좌·요율·수수료·공지 문구는 **실제 서비스의 값**입니다.
공개하기 전에 본인 내용으로 바꾸세요.

참고한 스크린샷 중 일부는 다른 회사(오마이집, 타배) 화면이라 **구성만 참고**하고
브랜드·메뉴·푸터·로고는 KURO Logi 것으로 바꿨습니다. 타배의 사업자 정보
(대표자·이메일·계좌번호)와 오마이집 고객의 개인정보는 **넣지 않았습니다.**
