# 종합현황 — 회원 대시보드

회원 로그인 후 보이는 종합현황 페이지입니다. KURO Logi 홈페이지와 같은
헤더·주 메뉴·푸터를 쓰고, 본문은 대시보드로 만들었습니다.

**순수 CSS** · Bootstrap 클래스 없음 · 데스크톱 전용

## 파일

| 파일 | 설명 |
|---|---|
| `dashboard.html` | 페이지 마크업 (동작하는 자바스크립트 없음) |
| `dashboard.css` | 전체 스타일 (약 16KB) |

브라우저로 `dashboard.html` 을 열면 됩니다.

## ⚠️ 먼저 읽어 주세요

**참고한 스크린샷은 다른 회사의 시스템입니다.**

주신 `마이페이지.png` 는 **오마이집(OhMyZip)** 의 회원 화면이고, 하단에
"ShipSmart Inc." 로고와 약관 링크가 있습니다. KURO Logi 의 화면이 아닙니다.

그래서 다음과 같이 만들었습니다:

| 항목 | 처리 |
|---|---|
| 화면 구성 (현황판, AI 카드, 나의 정보, 관리 메뉴, 주소, 공지/환율/1:1, FAQ) | **그대로 참고** — 배대지 대시보드의 일반적인 구성이라 문제 없습니다 |
| 브랜드·로고·헤더·메뉴·푸터 | **KURO Logi 것으로 교체** |
| 일본 사서함 주소 3개 | **KURO Logi 의 실제 센터 주소** (홈페이지에서 가져온 값) |
| 미국/중국/독일 주소, 전화번호, 이메일, 주문번호 | **넣지 않음** — 아래 참고 |

### 개인정보를 옮기지 않았습니다

원본 스크린샷에는 실제 고객으로 보이는 정보가 있었습니다:

- 미국 DE/CA 주소, 전화번호 2개 (`302-322-8792`, `714-676-7274`)
- 중국 주소, 휴대폰번호 (`15684513564`)
- 독일 회사명·주소·전화번호
- 회원명(`Jason Kim`), 회원번호(`KR0170395823`), 개인통관부호

다른 회사 고객의 개인정보일 가능성이 높아 **하나도 가져오지 않았습니다.**
대신 다음처럼 자리표시자를 넣었습니다:

- 회원명 → `회원님의 일본 사서함 주소`
- 회원번호 → `KR000000000`
- 주문번호 → `P0000000000`
- 등급 → `베이직(Basic)`, 포인트·예치금 → `¥0`

**실제로 쓰실 때 본인 회원 정보로 바꿔 주세요.**

## 확인한 것

- 브라우저 렌더링 확인 (1440px 캡처)
- 태그 짝 전부 일치 (`div`, `table`, `tr`, `td`, `th`, `ul`, `li`, `p`, `span` 등)
- CSS 중괄호 균형
- 로컬 경로 17개 전부 존재 (로고, 카톡 버튼)

## 확인하지 못한 것

- **로그인 후 실제 동작**은 확인할 수 없습니다. 원본 페이지는 서버에서
  회원 데이터를 받아오지만, 여기서는 값을 정적으로 넣었습니다.
- 숫자(1, 24, 5, 배지 2 등)는 스크린샷에 보이는 값을 그대로 옮겼습니다.
  실제 데이터가 아닙니다.
- 요약 탭은 색만 다르고 링크는 모두 `#` 입니다 (연결할 페이지가 없음).
- 드롭다운·복사 버튼 등은 자바스크립트 없이 겉모양만 구현했습니다.

`처리가까지` 는 `처리까지` 가 맞아서 고쳐 썼습니다.

## 확인하지 못한 것

- **실제 데이터 없음** — "조회된 신청서가 없습니다." 상태만 있습니다.
  표에 행이 들어갔을 때의 모양은 원본에 없어서 만들지 않았습니다.
- **자바스크립트 없음** — 탭 전환, 요청하기 버튼, 체크박스는 겉모양만입니다.
- 원본 스크린샷도 **ohmyzip.com** 화면입니다(`마이페이지.png` 와 같은 출처).
  구성만 참고하고 브랜드·메뉴·푸터는 KURO Logi 것으로 바꿨습니다.
- 사서함 주소·안내 문구는 KURO Logi 의 실제 값과 문구를 썼습니다.
