# 구매대행 · 배송대행 — 신청서 페이지

홈페이지와 같은 헤더·주 메뉴·푸터를 쓰는 신청 관련 페이지입니다.
**순수 CSS** · Bootstrap 클래스 없음 · 데스크톱 전용 · 자바스크립트 없음

## 파일

| 폴더 | HTML | CSS | 화면 |
|---|---|---|---|
| `배송대행/` | `order_form.html` | `order-form.css` | 배송대행 신청 (입력 폼) |
| `배송대행/` | `excel_upload.html` | `excel-upload.css` | 배송대행 엑셀대량등록 |
| `구매대행/` | `excel_upload.html` | `excel-upload.css` | 구매대행 엑셀대량등록 |

주 메뉴의 해당 항목에 연결되어 있습니다:

- 구매대행 → **구매대행 엑셀등록**
- 배송대행 → **주문서등록**, **배송대행 엑셀등록**

## 화면 구성

### 배송대행 신청 (`order_form.html`)

| # | 영역 | 내용 |
|---|---|---|
| 1 | 물류센터 및 운송방식 | 위해 / LCL 사업자(월/수/금) |
| 2 | 받는 사람 정보 | 한글·영문 이름, 우편번호 검색, 주소·상세주소(필수), 사업자번호, 휴대전화, 개인통관부호유효체크, 배송 요청사항 |
| 3 | 해외배송규정 안내 및 동의 | 25개 동의 항목 + 전체 동의하기 |
| 4 | 상품정보 입력 | 쇼핑몰·브랜드·오더번호·트래킹번호, 통관품목 검색, 영문 상품명, 수량/단가/색상/사이즈, URL, 오픈마켓 정보, HS CODE, 결제수단 |
| 5 | 금액정보 입력 | 총 수량 / 총 금액 ¥ / 총 금액 $, 목록통관 뱃지 |
| 6 | 부가서비스 | 6개 그룹 · 총 33개 옵션 (사진촬영·포장·통관·LCL·원산지·기타), 물류 요청사항 |
| 7 | 무게측정 후 자동 예치금 결제 | 자동결제 / 수동결제 |
| 8 | 안내 + 버튼 | 접수대기 / 접수신청 |

### 엑셀대량등록 (`excel_upload.html`)

| # | 영역 | 내용 |
|---|---|---|
| 1 | 엑셀 샘플 | 샘플다운 · 통관품목 목록다운 버튼, 2024.01.22 업데이트, 동의 안내 |
| 2 | 엑셀 대량 등록 | 신청 구분(배송대행/구매대행) · 발송국가·센터 선택 · 운송방식 선택, 파일찾기, 최대 10MB |
| 3 | 제출 | 등록 버튼 |

배송대행과 구매대행 두 페이지는 **같은 CSS**를 쓰고 신청 구분 기본값만 다릅니다.

## 원본과 다르게 한 부분

참고한 스크린샷은 **타배(tabae.co.kr)** 화면입니다. 구성만 참고하고
브랜드·메뉴·푸터·로고는 KURO Logi 것으로 바꿨습니다.

특히 **센터 목록을 바꿨습니다.** 원본은 미국(델라웨어/캘리포니아)·일본·중국·
독일·한국 6개국이지만, KURO Logi 는 일본 3개 센터만 운영합니다. 그래서
발송국가·센터 선택을 KURO Logi 의 실제 센터로 넣었습니다:

- 일본 > 항공 - 도쿄(JP)
- 일본 > 해상 - 후쿠오카 제1센터(JP)
- 일본 > 해상 - 후쿠오카 제2센터(JP)

또한 원본 하단의 사업자 정보(대표자·이메일·계좌번호)는 **넣지 않았습니다.**
타배의 실제 사업자 정보이기 때문입니다.

## 확인한 것

- 3개 페이지 브라우저 렌더링 확인 (1440px) — 상단·중단·하단 모두
- 태그 짝 전부 일치, CSS 중괄호 균형
- 주 메뉴 9개 항목 · 서브메뉴 8개 · 깨진 링크 0개
- 25개 동의 항목, 33개 부가서비스 옵션 전부 포함

## 확인하지 못한 것

- **자바스크립트 없음** — 체크박스, 파일 선택, 등록 버튼, 접수신청 모두
  겉모양만입니다. 실제 전송 기능은 없습니다.
- **입력값 검증 없음** — 필수 항목 표시(빨간 테두리)만 되어 있고,
  비었을 때 막는 동작은 없습니다.
- 원본의 접기/펼치기(▾) 동의 항목 상세 설명은 넣지 않았습니다.
  제목만 있고 눌러도 열리지 않습니다.
- 엑셀 샘플 파일은 실제로 받아지지 않습니다 (버튼만).
- 날짜(2024.01.22)와 요율·옵션 가격은 원본에 적힌 값 그대로입니다.
  실제 운영 전에 확인하세요.

## 참고 파일

`엑셀대량등록.png`, `배송대행 신청2.png` 는 작업용 참고 이미지입니다.
필요 없으면 지우셔도 됩니다.

`tools/build-forms.mjs` 가 이 3개 페이지를 만드는 스크립트이고,
`tools/sync-nav.mjs` 가 모든 페이지의 주 메뉴를 홈페이지와 동일하게
맞춰 줍니다. 메뉴를 고칠 때는 홈페이지를 수정한 뒤
`node tools/sync-nav.mjs` 를 실행하세요.
